Data & model — stated plainly

  • Live data: DB Timetables API (official, free tier). Single-station scope — it has no route search, so journeys are defined by leg rather than discovered automatically.
  • Training data: piebro/deutsche-bahn-data (CC BY 4.0), 5.6M before/after delay pairs.
  • Calibration: q90 coverage 90.7% (target 90%), q50 56.2% (target 50%). q10 is under-calibrated at 29% — disclosed, and not used for the risk decision.
  • Delay-cause codes: decoded via the community-maintained Travel::Status::DE::IRIS table. DB does not publish this mapping itself.
  • Prior art: transfer-probability prediction was demonstrated by Bahnvorhersage. This project's contribution is the live orchestration layer, not the prediction itself.
